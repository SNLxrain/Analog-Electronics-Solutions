# Analog Electronics Solutions

面向《模拟电子技术》基础课的**解题诊断**系统：学生分步提交解题过程，系统定位他**第一次**错在哪一步、错因是什么，并生成同考点、同难度的变式练习。

> 北京邮电大学人工智能学院 · 大学生创新创业训练计划项目
> 项目周期：2026.09 – 2027.06 ｜ 负责人：宋林睿

## 要解决的问题

模电是公认难学的工科基础课，很多同学的状态是"**答案看得懂、自己做不对**"。

传统题库只能判对错，判不出"从哪一步开始错的""为什么会错"。本项目补的就是这一层。

## 核心设计

### 1. 双模式验算

学生在错误的基础上继续往下算，系统不该把后面每一步都判成新的错误。
所以每一步都用两个基准分别判定：

- **模式 A**：用标准解法的**真值**判断这一步本身对不对
- **模式 B**：用**学生自己的前继结果**判断后续步骤是"又错了"，还是"只是继承了前面的错"

### 2. 符号等价判定

标准解法里的 `Ie` 和学生写的 `(1+β)Ib` 是同一个量，只是写法不同。
所以先把两边**迭代展开成基本参数**再比较 —— 既不受书写形式影响，也不受"有没有把中间量代入展开"影响。
（`canon` 是有向无环图，展开必然终止。）

### 3. 分带容差

| 相对偏差 | 判定 |
|---|---|
| ≤ 1% | 判对 |
| 1% ~ 10% | 近似 / 精度问题，提示需教师确认 |
| > 10% | 判错 |

另有**近似白名单**（教师认可的近似写法）与**物理合理性检查**（工作区、相位等）——
后者仅在方法本身无误时才提示，避免噪声。

## 模块

| 文件 | 作用 |
|---|---|
| `verifier.py` | 批改引擎：逐步判定、首次出错定位、错因归类 |
| `templates.py` | 题型模板：基本参数、标准解法分步定义、错误模式库 |
| `sympy_check_demo.py` | 符号计算校验演示 |
| `build_official.py` | 从源文档构建标准解法与题库 |
| `dump_docx.py` / `make_docx.py` | DOCX 读取与生成 |
| `run_demos.py` | 演示入口 |

## 快速开始

```bash
pip install sympy python-docx
python run_demos.py
```
